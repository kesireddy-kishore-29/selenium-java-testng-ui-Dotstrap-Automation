# pages/

Page objects. `Locators` is the only class that builds a `By` ([locator policy](../../../../../../../docs/locator-policy.md)); `BasePage` holds the driver and waits; `Accessible` reads role and name. Subfolders: `sauce` (Sauce Demo), `app` (the UI flagship's app), `live` (dotstrap.com, read-only), `demo` (deliberately wrong, for the failure demo).
